V0.5.22.69 – Pickup Button Fix

แก้ปัญหาออเดอร์ที่มีงานวินอยู่แล้ว แต่ยังไม่มีวินรับงาน ไม่เห็นปุ่ม:
  🏪 เปลี่ยนเป็นมารับเองที่ร้าน

หลักการ:
- แสดงปุ่มโดยตรงจากข้อมูล batch ไม่ใช้ setInterval/DOM decorator
- รองรับ batch เดิมที่สร้างก่อนอัปเดต ถ้ายังไม่มีวินรับ
- วินรับงานแล้ว ปุ่มจะไม่แสดง และ SQL ป้องกันการเปลี่ยนซ้ำ
- ยกเลิกเฉพาะงานวิน ไม่ยกเลิกออเดอร์สินค้า
- เปลี่ยน fulfillment_method ของชุดคำสั่งซื้อเป็น pickup
- ไม่แก้ delivery_fee เดิม และไม่มี refund ค่าวิน เพราะวินเก็บปลายทาง

ติดตั้ง:
1) นำไฟล์เว็บชุดนี้ทับ repo แล้ว Commit + Push
2) รัน upgrade-v0.5.22.69-switch-to-pickup-repair.sql ใน Supabase SQL Editor 1 ครั้ง
3) ไม่ต้องรัน SQL v0.5.22.66 หรือ v0.5.22.68 ซ้ำ
4) เปิดออเดอร์ TEST เดิมที่ยังรอวินรับงาน ควรเห็นปุ่มทันทีหลังหน้าเว็บโหลดเวอร์ชันใหม่
