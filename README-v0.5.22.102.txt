ตลาดกระทุ่มแบน V0.5.22.102 — ตัวกรองร้านที่มี Delivery

สิ่งที่เพิ่ม
- เพิ่มปุ่ม “🛵 ร้านที่มี Delivery” ในเมนูหมวดหมู่ทั้งหมด
- กรองร้านที่เปิด Delivery ของโครงการ
- รวมร้านที่ระบุบริการจัดส่ง, LINE MAN, Grab หรือ ShopeeFood
- ใช้ตัวกรองร่วมกับคำค้นหาและหมวดหมู่ร้านได้
- รายการร้านและหมุดแผนที่แสดงผลตามตัวกรองเดียวกัน
- กดปุ่มเดิมซ้ำเพื่อยกเลิกตัวกรอง

ความปลอดภัย
- ถ้าตารางสิทธิ์ Delivery ยังไม่พร้อม ระบบยังโหลดร้านทั่วไปได้ตามปกติ
- ไม่แก้ฐานข้อมูลและไม่ต้องรัน SQL
- รวมโค้ดเดิมจาก V0.5.22.101 และการลด Cached Egress จาก V0.5.22.100

วิธีติดตั้ง
1. วาง index.html, app.js, order.js, styles.css และ sw.js ทับไฟล์เดิม
2. Commit และ Push แล้วรอ Deploy สำเร็จ
3. ปิดหน้าเว็บเดิมและเปิดใหม่ หรือรีเฟรชแบบไม่ใช้แคชหนึ่งครั้ง
