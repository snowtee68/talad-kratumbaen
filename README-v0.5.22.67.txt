V0.5.22.67 - Switch Waiting Rider to Self Pickup (COD Fix)

แก้ตาม Flow จริงของระบบ:
- ค่าจัดส่งวินเรียกเก็บจากลูกค้าปลายทาง
- ลูกค้ายังไม่ได้จ่ายค่าจัดส่งให้ร้าน/ระบบตอนสั่ง
- ดังนั้นเมื่อเปลี่ยนเป็น “มารับเองที่ร้าน” จะไม่มีการคืนค่าจัดส่ง

พฤติกรรม:
- ลูกค้ากด “🏪 เปลี่ยนเป็นมารับเองที่ร้าน”
- ใช้ได้เฉพาะตอนยังไม่มีวินรับงาน
- ยกเลิกเฉพาะงานเรียกวิน
- ออเดอร์สินค้ายังอยู่ตามเดิม
- ค่าจัดส่ง = 0 สำหรับการรับเอง
- ไม่มีข้อความหรือ logic คืนเงินค่าจัดส่ง
