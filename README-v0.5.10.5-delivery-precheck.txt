V0.5.10.5 – Delivery Area Pre-check

ต่อจาก V0.5.10.4 และรวม Address UX + Fare Popup ไว้ครบ

เพิ่ม:
- ก่อนสร้างออเดอร์แบบ Delivery ระบบดึงพิกัดร้านทั้งหมดในตะกร้า
- คำนวณเส้นทางรวม ร้านต่าง ๆ -> ผู้รับ ก่อนสร้าง Order จริง
- ระบบลองเรียงจุดรับเพื่อหาเส้นทางที่สั้นที่สุด (รองรับสูงสุด 5 ร้าน)
- ถ้าเกิน 10 กม. จะไม่สร้างออเดอร์ และแนะนำ “รับเองที่ร้าน”
- ถ้าผ่าน จะแสดงระยะทางประมาณ + ค่าส่งเบื้องต้นก่อนสร้างออเดอร์
- การเรียกวินจริงใช้ลำดับจุดรับแบบเดียวกับการตรวจล่วงหน้า เพื่อลดความคลาดเคลื่อน
- สูตรค่าจัดส่งเดิมไม่เปลี่ยน
- Rider Live Sync เดิมไม่เปลี่ยน

ติดตั้ง:
- Deploy ZIP นี้ทับ main เดิม
- ไม่ต้อง Run SQL
- ไม่ต้องแก้ Edge Function
