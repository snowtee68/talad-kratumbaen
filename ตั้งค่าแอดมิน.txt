ตั้งค่าบัญชีแอดมิน

1) เปิดเว็บไซต์แล้วสมัครสมาชิกด้วยอีเมล snowtee68@gmail.com
2) กดยืนยันอีเมลจากกล่องจดหมาย
3) เข้า Supabase > SQL Editor > New query
4) วางคำสั่งด้านล่าง แล้วกด Run

update public.market_profiles
set role = 'admin'
where id = (
  select id from auth.users
  where email = 'snowtee68@gmail.com'
);

5) ออกจากระบบเว็บไซต์ แล้วเข้าสู่ระบบใหม่
6) เลื่อนลงไปที่ “ร้านที่รออนุมัติ” แล้วกดอนุมัติได้

ตรวจสอบว่าเป็นแอดมินแล้ว:

select p.id, u.email, p.display_name, p.role
from public.market_profiles p
join auth.users u on u.id = p.id
where u.email = 'snowtee68@gmail.com';
