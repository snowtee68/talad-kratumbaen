ตลาดกระทุ่มแบน V0.5.22.107 — เลขอ้างอิงเดียวกันทั้งระบบ

- หน้าลูกค้าใช้เลขอ้างอิงจากชุดคำสั่งซื้อ
- หน้าร้านแสดงเลขชุดคำสั่งซื้อเดียวกับลูกค้า แทนเลข order ภายในของแต่ละร้าน
- สถานะ Delivery ไม่แสดงเลข batch ภายในเป็นเลขหลักอีก
- หน้างาน Rider แสดงเลขอ้างอิงเดียวกับลูกค้าและร้านค้า
- รองรับงานเดิม โดยอ่าน group_id จาก Delivery batch หรือหมายเหตุงานเดิม

รหัส order_id, batch_id และ rider_job_id ภายในฐานข้อมูลยังคงเดิม เพื่อไม่กระทบ
การชำระเงิน การรับงาน การอัปเดตสถานะ และประวัติเดิม

ติดตั้งโดยวางทับ:
- index.html
- app.js
- order.js
- sw.js
- rider/index.html
- rider/app.js
- rider/styles.css

ไม่ต้องรัน SQL และไม่ต้อง Deploy Edge Function เพิ่ม
