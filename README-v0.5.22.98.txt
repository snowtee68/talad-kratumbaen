V0.5.22.98 – RIDER READY BUTTON

แก้ไข:
- เปลี่ยนช่องติ๊กเล็กเป็นปุ่มขนาดใหญ่ "เปิดรับงาน / พักรับงาน"
- แสดงสถานะและคำอธิบายให้ Rider เห็นชัดเจน
- ใช้งานได้เฉพาะบัญชี Rider ที่ได้รับอนุมัติแล้ว
- เมื่อเปิดรับงาน ระบบบันทึก rider_profiles.online = true
- Push งานใหม่ส่งเฉพาะ Rider ที่อนุมัติและเปิดรับงาน
- เมื่อพักรับงาน จะไม่ได้รับ Push งานใหม่
- การแจ้งเตือนหลังรับงานแล้ว ยังส่งตรงถึง Rider เจ้าของงานตามเดิม

ติดตั้ง:
1. รัน upgrade-v0.5.22.98-rider-ready-button.sql ใน Supabase SQL Editor 1 ครั้ง
2. วางทับ rider/index.html, rider/app.js และ rider/styles.css โดยรักษาโฟลเดอร์ rider
3. Commit และ Push
4. Rider ปิดแอปแล้วเปิดใหม่ หรือรีเฟรชหน้า 1 ครั้ง
