ตลาดกระทุ่มแบน V0.5.22.100 — ลด Supabase Cached Egress

สิ่งที่แก้ไข
- รูปหน้าร้านใหม่: WebP สูงสุดประมาณ 450 KB และด้านยาวไม่เกิน 1200 px
- รูปโปรโมชั่นใหม่: WebP สูงสุดประมาณ 450 KB ขนาดไม่เกิน 1200 x 900 px
- รูปสินค้าใหม่: WebP สูงสุดประมาณ 220 KB และด้านยาวไม่เกิน 1000 px
- รูป QR รับเงินใหม่: WebP สูงสุดประมาณ 250 KB และตั้ง Browser Cache ระยะยาว
- รูปสินค้าในหน้าสั่งซื้อใช้ Lazy Loading และถอดรหัสรูปแบบ async
- Service Worker เก็บรูปสาธารณะจาก Supabase ไว้ในเครื่องหลังโหลดครั้งแรก

ผลต่อผู้ใช้งาน
- ฟังก์ชันร้านค้า ออเดอร์ คูปอง Mission Delivery และ Rider ทำงานเหมือนเดิม
- รูปเดิมใน Supabase ไม่ถูกลบหรือแก้ไข
- รูปใหม่ใช้พื้นที่และ Cached Egress น้อยลง
- การกลับมาเปิดรูปเดิมบนอุปกรณ์เดิมสามารถอ่านจากแคชในเครื่องได้

วิธีติดตั้ง
1. หากยังไม่เคยติดตั้ง V0.5.22.99 ให้รัน upgrade-v0.5.22.99-rider-availability-sync.sql ก่อน
2. วางไฟล์ทั้งหมดทับของเดิม โดยรักษาโฟลเดอร์ rider และ .github
3. Commit และ Push
4. รอ Deploy สำเร็จ แล้วปิด/เปิดเว็บหรือรีเฟรชแบบไม่ใช้แคชหนึ่งครั้ง
