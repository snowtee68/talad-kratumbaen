ตลาดกระทุ่มแบน V0.5.22.113 — Notification Route Scope Fix

แก้สาเหตุที่ต้องกดสองครั้ง:
- Service Worker บันทึกเส้นทางจาก Notification ตาม scope ของ PWA
- หน้าเว็บเดิมอ่านเส้นทางโดยอ้างอิง location.href ซึ่งอาจเป็นคนละตำแหน่งเมื่อ URL ไม่มี / ท้ายชื่อหรือเปิดจากไอคอน PWA
- ปรับหน้าเว็บให้อ่านและล้างเส้นทางโดยใช้ Service Worker scope เดียวกับจุดที่บันทึก

ผลลัพธ์ที่ต้องได้:
- กด Notification ตอนพักหน้าจอหนึ่งครั้ง
- PWA เปิดขึ้นมาและเข้าหน้าออเดอร์ที่ร้านได้รับโดยอัตโนมัติ
- ไม่ต้องกดแถบ "มีออเดอร์ใหม่" ด้านบนซ้ำ

ติดตั้ง:
1. ต้องมี V0.5.22.108 แล้ว
2. วาง index.html, app.js, order.js และ sw.js ทับไฟล์เดิม
3. ไม่ต้องลง .109-.112 แยก
4. ไม่ต้องรัน SQL และไม่ต้อง Deploy Edge Function
5. ปิด PWA ให้สนิท เปิดใหม่ และตรวจให้เห็นเวอร์ชัน V0.5.22.113
6. ล้าง Notification เก่า แล้วสร้างออเดอร์ใหม่เพื่อทดสอบ
