V0.5.10.7 – Cascading Address Dropdown

ต่อจาก V0.5.10.6 Realtime และรวมระบบก่อนหน้าทั้งหมด

เพิ่ม UX ที่อยู่:
- จังหวัด -> อำเภอ/เขต -> ตำบล/แขวง เป็น Dropdown สัมพันธ์กัน
- เลือกตำบลแล้วเติมรหัสไปรษณีย์อัตโนมัติ
- บ้านเลขที่/หมู่/ซอย/ถนน/จุดสังเกตยังพิมพ์เอง
- ค่าเริ่มต้น สมุทรสาคร -> กระทุ่มแบน
- รองรับพื้นที่รอยต่อที่เกี่ยวข้องกับรัศมี Delivery ปัจจุบัน:
  สมุทรสาคร, นครปฐม (สามพราน/พุทธมณฑล), กรุงเทพฯ (หนองแขม/บางบอน/บางแค)
- กฎตัดสินส่งได้ยังคงเป็น “เส้นทางรวมไม่เกิน 10 กม.” จาก V0.5.10.5
- ที่อยู่ที่บันทึกไว้จะถูกโหลดกลับเข้า Dropdown อัตโนมัติ

หมายเหตุ:
รายการ Dropdown ชุดนี้เน้นพื้นที่ที่มีโอกาสอยู่ในระยะบริการ 10 กม. ของตลาดกระทุ่มแบน
ไม่ใช่ฐานตำบลทั้งประเทศไทย เพื่อไม่เพิ่มไฟล์ข้อมูลขนาดใหญ่โดยไม่จำเป็น

ติดตั้ง:
- Deploy ZIP ทับ main
- ไม่ต้อง Run SQL เพิ่ม (แต่ต้องเคย Run upgrade-v0.5.10.6-realtime.sql)
- ไม่ต้องแก้ Edge Function
