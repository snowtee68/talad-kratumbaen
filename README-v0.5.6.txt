Talad Kratumbaen v0.5.6 — Seller Order Queue

ต่อจากโปรเจกต์ล่าสุดที่ผู้ใช้ส่งมา (มี v0.5.5 แล้ว)

เพิ่มฝั่งร้าน:
- ออเดอร์ในแต่ละ Tab เรียงตาม “สิ่งที่ต้องทำก่อน” แล้วเรียงออเดอร์เก่าก่อน
- payment_review / pending_shop / refund จะขึ้นก่อนงานที่รอเฉย ๆ
- แสดงอายุออเดอร์ เช่น 8 นาที / 1 ชม. 20 นาที
- ออเดอร์ pending_shop ที่เกินเวลาเน้นสีเร่งด่วน
- Tab “ต้องทำตอนนี้” มีจำนวนงานเด่นและข้อความบอกว่าจัดคิวตามความเร่งด่วน
- ไม่เปลี่ยน workflow เดิม, Push, Auto Accept, Refund, Delivery/Pickup

ติดตั้ง:
- ใช้ ZIP นี้ Deploy แทนโปรเจกต์เดิมได้เลย
- ไม่ต้อง Run SQL
- index.html อ้าง order.js?v=0.5.6 แล้ว
