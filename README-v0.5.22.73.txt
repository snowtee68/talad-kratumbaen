V0.5.22.73 – Order Role Choice + Seller Push Notifications

รวม V0.5.22.72 และเพิ่มการแจ้งเตือนฝั่งร้านค้า

คงการแก้จาก 22.72:
- บัญชีเจ้าของร้านกด “ออเดอร์” จะมีตัวเลือกเสมอ
  🛒 ออเดอร์ที่ฉันสั่งซื้อ
  🏪 ออเดอร์ที่ร้านได้รับ
- ไม่เด้งเข้าฝั่งร้านอัตโนมัติตาม activeSellerOrders
- พฤติกรรมเดียวกัน Mobile / iPad / Android Tablet / PC

เพิ่มใน 22.73:
- หน้า “ออเดอร์ที่ร้านได้รับ” มีการ์ด:
  🔔 การแจ้งเตือนออเดอร์ร้าน
- ปุ่มเปิดแจ้งเตือนออเดอร์ร้าน
- ปุ่มปิดการแจ้งเตือนเครื่องนี้
- ปุ่มส่งแจ้งเตือนทดสอบ
- ใช้ Web Push เดิมของระบบ จึงรองรับการแจ้งเตือนขณะปิดหน้าเว็บ/พักหน้าจอ ตามสิทธิ์ของ OS/Browser
- ใช้ Push subscription เดียวของบัญชีบนอุปกรณ์นั้น เพื่อไม่สร้าง subscription ซ้ำ
- Trigger/Edge Function เดิมของ order-push-webhook / send-order-push ทำงานต่อ ไม่เพิ่มการส่งซ้ำจาก frontend

หมายเหตุ:
- ปุ่ม “ปิดการแจ้งเตือนเครื่องนี้” ปิด subscription ของบัญชีบนอุปกรณ์นั้นทั้งหมด ดังนั้นฝั่งลูกค้า/ร้าน/วินบนเครื่องเดียวกันจะหยุด Push ด้วย
- นี่เป็นพฤติกรรมตามโครงสร้าง Push subscription ปัจจุบัน และมีข้อความแจ้งไว้ใน UI
- ไม่มี SQL ใหม่

ติดตั้ง:
1) แตก ZIP ทับไฟล์เดิม
2) Commit + Push GitHub
3) Refresh / ปิดเปิด PWA ใหม่
4) เข้า ออเดอร์ > ออเดอร์ที่ร้านได้รับ และกด “เปิดแจ้งเตือนออเดอร์ร้าน”
