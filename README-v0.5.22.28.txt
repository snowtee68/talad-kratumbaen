V0.5.22.28 - Mobile Navigation Redesign

ปรับเฉพาะ UI/Navigation บนมือถือ:
- คง Logo เดิม “ต” และธีมสีแดงเดิม
- เมนูลัดด้านบน: ร้านชื่นชอบ / Mission / สมัครเป็นวิน-งานวิน / เพิ่มเติม
- เมนู “เพิ่มเติม”: ร้านใกล้ฉัน / เพิ่มร้าน / ติดตั้งแอป / สมัครสมาชิก (เฉพาะ guest) / ติดต่อ
- Bottom Taskbar: หน้าหลัก / ออเดอร์ / คูปองของฉัน / ร้านของฉัน
- รองรับ iPhone Safe Area
- ปุ่มใหม่เป็น proxy เรียกปุ่ม/function เดิม จึงไม่เปลี่ยน business logic
- Desktop ยังคงรูปแบบเดิม
- ไม่แก้ Order / Delivery / Rider Jobs / Mission / Coupon logic
- ไม่ต้องรัน SQL เพิ่ม
