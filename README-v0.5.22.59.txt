V0.5.22.59 - Rider Approval Registry Fix

รวม V0.5.22.58 ทั้งหมด

แก้ปัญหา:
Admin อนุมัติวินที่สมัครใหม่แล้ว แต่ไม่ปรากฏในหัวข้อ “วินในระบบ”

สาเหตุ:
ใบสมัครอยู่ใน market_rider_applications แต่หน้า “วินในระบบ” และ flow รับงาน
ใช้ rider_profiles เป็นทะเบียนบัญชีวินหลัก

สิ่งที่แก้:
1. Admin อนุมัติ -> สร้าง/อัปเดต rider_profiles ด้วย user_id เดียวกันทันที
2. SQL ซ่อมวินที่เคยอนุมัติไปแล้วก่อนหน้านี้ให้อัตโนมัติ
3. ชื่อ/เบอร์ของวินที่แก้ภายหลัง sync ไป rider_profiles
4. หลัง Admin อนุมัติ หน้า Admin reload รายชื่อวินใหม่ทันที
5. ไม่ลบทะเบียนวินเดิม และไม่กระทบประวัติงาน Delivery
