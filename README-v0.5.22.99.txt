ตลาดกระทุ่มแบน V0.5.22.99 — Rider Availability Sync

สิ่งที่แก้ไข
- ซ่อม Rider ที่อนุมัติแล้วแต่ยังไม่มีข้อมูลใน rider_profiles
- แสดงปุ่ม “เปิดรับงาน / พักรับงาน” หลังอนุมัติ
- เปลี่ยนสถานะผ่าน RPC เพื่อไม่ติดสิทธิ์ RLS ของตาราง
- ส่ง Push งานใหม่เฉพาะ Rider ที่อนุมัติและเปิดรับงาน
- อัปเดตเลขเวอร์ชันหน้าเว็บหลักและ Service Worker เป็น V0.5.22.99
- อัปเดต GitHub Pages Actions เป็นรุ่นที่รองรับ Node.js 24 โดยไม่แก้ Node.js ของโครงการ

วิธีติดตั้ง
1. รัน upgrade-v0.5.22.99-rider-availability-sync.sql ใน Supabase SQL Editor หนึ่งครั้ง
2. วางไฟล์เว็บทั้งหมดทับของเดิม โดยรักษาโฟลเดอร์ rider
   และวาง .github/workflows/pages-recovery.yml ทับ workflow เดิม
3. Commit และ Push แล้วรอ GitHub Pages deploy สำเร็จ
4. ปิดหน้าเว็บเดิม เปิดใหม่ หรือรีเฟรชแบบไม่ใช้แคชหนึ่งครั้ง

หมายเหตุ
- ไม่ต้องรัน SQL V0.5.22.98 แยก หากติดตั้ง V0.5.22.99 นี้
- Rider เดิมที่เปิดรับงานอยู่ จะไม่ถูกเปลี่ยนเป็นพักรับงาน
