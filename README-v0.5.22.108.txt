ตลาดกระทุ่มแบน V0.5.22.108 — Background Push Repair

แก้ไข:
- ฝั่งร้านค้าและลูกค้า ตรวจสอบ Push subscription กับฐานข้อมูลจริงเมื่อเปิดหน้าตั้งค่าการแจ้งเตือน
- หากข้อมูลอุปกรณ์ฝั่งเซิร์ฟเวอร์หาย ระบบซ่อมหรือสร้าง subscription ใหม่ให้อัตโนมัติ
- ฝั่ง Rider สร้าง Push subscription ใหม่หนึ่งครั้งหลังอัปเดตรุ่นนี้ และบันทึกกลับฐานข้อมูล
- อัปเดต Service Worker ทั้งเว็บหลักและหน้า Rider
- รวม rider/sw.js ในชุดอัปเดต เพื่อป้องกันไฟล์ Service Worker ของ Rider ตกหล่น

ติดตั้ง:
1. วางไฟล์ทั้งหมดใน ZIP ทับไฟล์เดิม โดยรักษาโฟลเดอร์ rider
2. ไม่ต้องรัน SQL
3. ไม่ต้อง Deploy Edge Function ใหม่
4. เปิด Web App/PWA หนึ่งครั้งหลังอัปเดต
5. ร้านค้าเปิดหน้า "ออเดอร์ที่ร้านได้รับ" เพื่อตรวจสถานะ Push
6. Rider เปิดหน้า Rider หนึ่งครั้ง ระบบจะซ่อม subscription อัตโนมัติ
7. หากระบบแจ้งว่ายังไม่เปิด Push ให้กดเปิดการแจ้งเตือนอีกครั้ง

หมายเหตุ:
- ระบบยังใช้ VAPID Key เดิม
- การแจ้งเตือนขณะพักหน้าจอขึ้นกับการอนุญาต Notification และการตั้งค่าพลังงาน/การแจ้งเตือนของอุปกรณ์
