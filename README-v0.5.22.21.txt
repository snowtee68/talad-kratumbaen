V0.5.22.21 UNIVERSAL INSTALL
ใช้ชุดนี้แทน V0.5.22.21 ตัวก่อนหน้า

ปุ่มเดียว: 📲 ติดตั้ง ตลาดกระทุ่มแบน

Android Chrome:
- ถ้า PWA พร้อม -> เปิด Install ของ Android โดยตรง

Android LINE/Facebook/Instagram:
- พยายามเปิด URL เดิมใน Google Chrome
- มีปุ่ม “เปิดด้วย Chrome” สำรอง
- ไม่พยายามติดตั้งใน in-app browser

Samsung Internet:
- แนะนำ/ส่งไป Chrome เพื่อลดปัญหา Play Protect

iPhone/iPad Safari:
- แสดง Share -> เพิ่มไปยังหน้าจอโฮม -> เพิ่ม

iPhone/iPad LINE/Facebook/Instagram:
- แนะนำเปิด Safari ก่อน แล้ว Add to Home Screen

หมายเหตุ:
Android/iOS ไม่อนุญาตให้เว็บไซต์บังคับเปิดแอปอื่นได้ 100% ทุกเครื่อง จึงมี fallback เสมอ
ไม่ต้องรัน SQL เพิ่ม
