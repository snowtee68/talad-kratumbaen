V0.5.22.23 - Mobile Display Name Editor

แก้ปัญหา:
- PC เห็นส่วนแก้ไขชื่อ แต่บนมือถือหาไม่เจอ/เข้าถึงยาก

ปรับใหม่:
- มือถือ: กด “บัญชี/ร้านของฉัน” หลัง Login -> เปิดหน้าต่างแก้ไขชื่อโดยตรง
- กดชื่อผู้ใช้ด้านบน -> เปิดแก้ไขชื่อได้ทั้ง PC และมือถือ
- PC ยังคงมีส่วนแก้ไขชื่อในหน้า บัญชีของฉัน เหมือนเดิม
- ถ้ายังไม่ตั้งชื่อแล้วกดรีวิว -> เปิดหน้าต่างตั้งชื่อให้ทันที
- ใช้ระบบ Display Name และ SQL ของ V0.5.22.22 เดิม

ไม่ต้องรัน SQL เพิ่ม หากรัน V0.5.22.22 แล้ว
