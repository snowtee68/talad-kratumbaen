# ตลาดกระทุ่มแบน Main v4.4

พัฒนาต่อจาก Main v4.3 โดยไม่เปลี่ยนระบบร้านค้าเดิม

## สิ่งที่เพิ่ม
- ร้านสร้างโปรโมชั่นล่วงหน้าได้ไม่จำกัด
- ช่วงเวลาโปรโมชั่นซ้อนกันได้สูงสุด 3 โปรโมชั่นต่อร้าน
- หลังเข้าสู่ระบบ เจ้าของร้านกด “จัดการโปรโมชั่น” เพื่อดูโปรทั้งหมดของร้าน
- ลบโปรโมชั่นได้ พร้อมกล่องยืนยันก่อนลบ
- แสดงสถานะ กำลังใช้งาน / กำลังจะเริ่ม / หมดอายุ / ปิดใช้งาน
- ลบโปรโมชั่นแล้วหน้าเว็บอัปเดตทันที

## วิธีติดตั้ง
1. รัน `อัปเกรดโปรโมชั่น-v4.4.sql` ใน Supabase SQL Editor หนึ่งครั้ง
2. อัปโหลด `index.html`, `app.js`, `styles.css`, `config.js` และ `netlify.toml` ทับไฟล์เดิมใน Branch `main`
3. Commit และ Push
4. รอ GitHub Pages อัปเดต แล้วกด Ctrl+F5

## วิธีลบโปรโมชั่น
1. เข้าสู่ระบบด้วยบัญชีเจ้าของร้าน
2. เลื่อนไปที่ “ร้านที่ฉันดูแล”
3. กด “จัดการโปรโมชั่น”
4. กด “ลบโปรโมชั่น” ที่รายการที่ต้องการ
5. ยืนยันการลบ

โปรที่ลบแล้วไม่สามารถกู้คืนได้
