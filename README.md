# ตลาดกระทุ่มแบน Main v4.3

เว็บไซต์ HTML + JavaScript + Supabase สำหรับ GitHub Pages/Netlify เดิม

ฟังก์ชันหลัก:
- สมัคร/เข้าสู่ระบบด้วย Email + Password
- ลืมรหัสผ่านและตั้งรหัสผ่านใหม่
- เจ้าของร้านเพิ่มและแก้ไขร้านของตนเอง
- เวลาเปิด–ปิดรายวัน 7 วัน
- ปิดชั่วคราว / เปิด 24 ชั่วโมง
- ข้อมูลตำแหน่งและบริการร้าน
- อัปโหลดรูปหน้าปก
- แอดมินอนุมัติหรือปฏิเสธร้าน
- หน้าแผนที่และร้านใกล้ฉัน

เริ่มจากไฟล์ `เริ่มที่นี่.txt`


## อัปเดต v4.2
- แสดงร้านครั้งแรก 10 ร้าน และกดดูเพิ่มครั้งละ 10 ร้าน
- โปรโมชั่นที่ตั้งเวลาไว้ล่วงหน้าจะแสดงทันที
- ระบุชัดว่าโปรโมชั่น “กำลังใช้ได้” หรือ “เร็ว ๆ นี้”
- แสดงวันเริ่มและวันสิ้นสุดบนการ์ดโปรโมชั่นและหน้าร้าน
- ตัวกรอง “มีโปรโมชั่น” รวมทั้งโปรปัจจุบันและโปรที่กำลังจะเริ่ม

หมายเหตุ: หน้าเว็บแสดงทีละ 10 ร้านแล้ว แต่ยังดึงร้านที่อนุมัติทั้งหมดจาก Supabase มายังเบราว์เซอร์ เหมาะกับหลักสิบถึงหลักร้อยร้าน หากมีหลายพันร้านควรเปลี่ยนเป็น server-side pagination


Main v4.3 เพิ่มปุ่มดูโปรโมชั่นทั้งหมด แสดงโปรที่กำลังใช้และโปรล่วงหน้าพร้อมวันเริ่ม โดยหน้าแรกยังแสดง 6 รายการเพื่อไม่ให้หน้ายาวเกินไป
