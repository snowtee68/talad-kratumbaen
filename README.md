# ตลาดกระทุ่มแบน — Phase 2 พร้อมใช้งาน

ระบบนี้เชื่อมกับ Supabase เดิมและใช้ตาราง `market_*` ที่สร้างไว้แล้ว

## ฟังก์ชัน
- สมัครสมาชิก / เข้าสู่ระบบ
- เจ้าของร้านเพิ่มร้านและแก้ไขร้านของตนเอง
- อัปโหลดรูปหน้าร้าน
- ร้านที่เพิ่มหรือแก้ไขจะอยู่ในสถานะรอตรวจสอบ
- แอดมินอนุมัติหรือไม่อนุมัติร้านจากหน้าเว็บไซต์
- ร้านที่อนุมัติแล้วจะแสดงต่อสาธารณะ

## ติดตั้งขึ้น GitHub
1. แตกไฟล์ ZIP
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง repository `talad-kratumbaen`
3. เลือก Replace/เขียนทับไฟล์เดิมเมื่อชื่อซ้ำ
4. Commit changes
5. รอ Netlify deploy ประมาณ 1–2 นาที

## ตั้งแอดมิน
อ่านไฟล์ `ตั้งค่าแอดมิน.txt`

## หมายเหตุ
`config.js` ตั้งค่า Supabase URL และ publishable key ไว้แล้ว ห้ามใส่ secret/service-role key ในไฟล์เว็บไซต์
