V0.5.20.11 – Custom Product Categories
- แต่ละร้านสร้างชื่อหมวดหมู่เองได้ สูงสุด 30 หมวด
- แก้ชื่อ / ลบ / เลื่อนขึ้นลงได้
- ลบหมวดไม่ลบสินค้า สินค้าจะไปอยู่ “อื่น ๆ”
- เพิ่ม/แก้สินค้ามี dropdown เลือกหมวด
- หลังร้านจัดสินค้าแยกตามหมวด
- หน้าลูกค้ามีแถบ ทั้งหมด | หมวดต่าง ๆ | อื่น ๆ และกรองได้ทันที
- ร้านอื่นมีหมวดของตัวเอง ไม่ใช้หมวดกลางร่วมกัน
- ต้อง Run SQL ก่อน Deploy เว็บ
