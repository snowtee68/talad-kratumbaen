V0.5.22.78 – Rider New Job Sound + Shop Ready Push
รวม V0.5.22.77 ไว้แล้ว

แก้ 2 เรื่องตาม Flow ที่ตกลงกัน

1) งานวินใหม่
ยืนยันรับเงิน -> Auto Rider สร้างงาน -> send-rider-push แจ้งวินที่ได้รับอนุมัติ
- ฝั่งวินที่เปิดหน้า/PWA อยู่: งานใหม่จะถูกตรวจเป็น NEW และเล่นเสียงแจ้งเตือน
- ฝั่งพัก/ล็อกหน้าจอ: ใช้ Web Push + Service Worker เดิม
- เก็บ waiting job IDs ไว้ในเครื่อง เพื่อไม่ให้ "งานใหม่ที่เข้ามาตอนยังไม่ได้เปิดหน้างานวิน"
  กลายเป็น baseline เงียบเมื่อเปิดหน้าในภายหลัง
- Edge Function คืนค่า sent/failed/recipient ชัดเจนขึ้นเพื่อไล่ปัญหาได้

2) ปุ่ม “พร้อมจัดส่ง” ของร้าน
ปุ่มนี้ยังมี และมีความหมายใหม่ที่ชัดเจน:
- ไม่เรียกวินซ้ำ
- เปลี่ยน order เป็น ready
- ลูกค้ายังเห็นว่าสินค้าพร้อม
- ถ้ามีวินรับ batch แล้ว -> Push เฉพาะวินคนนั้นว่า
  “ร้าน X เตรียมสินค้าเสร็จแล้ว เข้ารับได้เลย”
- ถ้ายังไม่มีวินรับ -> ไม่ Push วินทุกคนซ้ำ แต่หน้างานวินจะแสดงสถานะร้านว่า ready
- หน้าวินแสดงแต่ละจุดรับ:
  ✅ สินค้าพร้อมให้เข้ารับ
  ⏳ ร้านกำลังเตรียมสินค้า

Flow:
ร้านยืนยันรับเงิน
→ Auto Rider เรียกวินทันที
→ วินทุกคนที่อนุมัติได้รับงานใหม่
→ วินหนึ่งคนกดรับ
→ ร้านเตรียมสินค้า
→ ร้านกด “พร้อมจัดส่ง”
→ Push เฉพาะวินเจ้าของงาน
→ วินเข้ารับ

ติดตั้ง:
A) อัป ZIP ทับ repo แล้ว Commit + Push
B) Supabase SQL Editor รัน ONCE:
   upgrade-v0.5.22.78-rider-sound-ready-push.sql
C) Redeploy Edge Function ชื่อเดิม:
   send-rider-push
   โดยใช้ไฟล์ supabase/functions/send-rider-push/index.ts ใน ZIP นี้
D) ไม่ต้องสร้าง VAPID ใหม่ และไม่ต้องเปลี่ยน Secrets ถ้า Push เดิมเคยตั้งไว้แล้ว

สำคัญเรื่อง “เสียง”:
Web App สามารถกำหนดให้ notification ไม่เป็น silent และสั่นได้
แต่เสียงตอนหน้าจอล็อก/พัก โดยเฉพาะ iPhone/iPad ยังขึ้นกับ Notification permission,
โหมดเงียบ/Focus และนโยบายเสียงของระบบปฏิบัติการ ไม่สามารถบังคับระดับเสียงจาก Web Push ได้

ทดสอบ:
1. วิน Login และเปิดแจ้งเตือนงานวินบนเครื่องนั้น
2. สร้าง Delivery ใหม่ -> ร้านยืนยันรับเงิน
3. ตรวจหน้าวิน: ต้องมีงาน + มีเสียงในหน้าเมื่อ PWA active
4. ตรวจ Push: งานใหม่ควรขึ้น “🛵 มีงานวินใหม่”
5. วินกดรับงาน
6. ร้านกด “พร้อมจัดส่ง”
7. วินคนที่รับงานต้องได้ Push “📦 สินค้าพร้อมให้เข้ารับแล้ว”
8. วินคนอื่นไม่ควรได้ Push พร้อมจัดส่งของงานนั้น
