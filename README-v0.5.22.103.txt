ตลาดกระทุ่มแบน V0.5.22.103 — ค้นหาร้านใน Admin และจัดลำดับ Delivery

สิ่งที่เพิ่ม
- เพิ่มช่องค้นหาในเมนู Admin > ร้านค้า
- ค้นหาได้จากชื่อร้าน หมวดหมู่ เบอร์โทร ที่อยู่ จุดสังเกต โซน และสถานะ
- กรองพร้อมกันทั้งรายการรออนุมัติและร้านค้าทั้งหมดทันทีขณะพิมพ์
- แสดงจำนวนร้านที่พบ พร้อมปุ่มล้างคำค้นและรองรับหน้าจอมือถือ
- เมื่อเลือก “ร้านที่มี Delivery” ร้านที่เปิด Delivery ของโครงการจะแสดงก่อนร้านจากแพลตฟอร์มอื่น
- การเรียงตามคะแนน ร้านใหม่ ชื่อ หรือระยะทาง ยังทำงานภายในแต่ละกลุ่มตามเดิม

วิธีติดตั้ง
1. วางไฟล์ index.html, app.js, order.js, styles.css และ sw.js ทับไฟล์เดิม
2. Commit และ Push ตามปกติ
3. หลัง Deploy สำเร็จ ให้รีเฟรชหนึ่งครั้ง หากยังเห็นรุ่นเก่าให้ปิดแท็บแล้วเปิดใหม่

รุ่นนี้ไม่ต้องรัน SQL เพิ่ม และไม่เปลี่ยนข้อมูลร้านหรือสิทธิ์เดิม
