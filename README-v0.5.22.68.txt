V0.5.22.68 - Auto Call Rider After Payment Confirmation

Flow ใหม่:
ร้านรับออเดอร์ → ลูกค้าโอน/ส่งสลิป → ร้านกด “เงินเข้าแล้ว / เริ่มเตรียม”
→ ระบบเรียกวินอัตโนมัติ → วินรับงาน → ร้านเตรียมสินค้า
→ วินรับสินค้า → ส่งลูกค้า → ลูกค้ายืนยันได้รับสินค้า

หลายร้านในชุดเดียวกัน:
ระบบรอให้ร้านที่ยังไม่ยกเลิกยืนยันรับเงินครบ แล้วเรียกวินรวมเที่ยวเดียว
เพื่อลดค่าส่งและไม่สร้างงานวินซ้ำ

รับเองที่ร้าน:
ไม่เรียกวิน

ค่าจัดส่ง:
เก็บจากลูกค้าปลายทาง (recipient)

ยังคง V0.5.22.67:
ถ้ายังไม่มีวินรับ ลูกค้าสามารถเปลี่ยนเป็น “มารับเองที่ร้าน”
ถ้าวินรับงานแล้วจะเปลี่ยนไม่ได้
