ตลาดกระทุ่มแบน V0.5.22.101 — ปุ่มเปิดรับงานในหน้าเว็บหลัก

ต้นเหตุที่ V0.5.22.99 ยังไม่เห็นปุ่ม
- ปุ่มเดิมถูกเพิ่มในหน้า /rider/ เท่านั้น
- หน้า “งาน Rider” บนเว็บหลักยังไม่มีส่วนควบคุมสถานะ

สิ่งที่แก้ไข
- เพิ่มปุ่ม “เปิดรับงาน / พักรับงาน” ใต้ข้อมูล Rider ที่อนุมัติแล้วในหน้าเว็บหลัก
- โหลดสถานะ online ล่าสุดจาก rider_profiles ผ่าน RPC
- เปิดรับงาน: เริ่มรับ Push และ Realtime แจ้งงานใหม่
- พักรับงาน: หยุด Push ที่ฝั่งเซิร์ฟเวอร์และหยุด Realtime/เสียงบนหน้าเว็บหลัก
- ยังคงปุ่มเดียวกันในหน้า /rider/
- รวมการลด Supabase Cached Egress จาก V0.5.22.100
- รวม GitHub Actions รุ่น Node.js 24

วิธีติดตั้ง
1. รัน upgrade-v0.5.22.99-rider-availability-sync.sql ใน Supabase SQL Editor หากยังไม่เคยรัน
2. ถ้าเคยรัน SQL นี้สำเร็จแล้ว ไม่ต้องรันซ้ำ
3. วางไฟล์ทั้งหมดทับของเดิม โดยรักษาโฟลเดอร์ rider และ .github
4. Commit และ Push แล้วรอ Deploy สำเร็จ
5. ปิดหน้าเว็บเดิมและเปิดใหม่ หรือรีเฟรชแบบไม่ใช้แคชหนึ่งครั้ง

วิธีตรวจ
เข้าสู่ระบบด้วยบัญชี Rider ที่อนุมัติแล้ว > กด “งาน Rider” > ปุ่มสถานะอยู่ใต้ข้อมูลชื่อ เบอร์ และทะเบียนรถ
