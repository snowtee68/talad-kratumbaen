ตลาดกระทุ่มแบน V0.5.22.111 — Seller Push and Banner Direct Order Fix

แก้ไข:
- Service Worker เก็บ event, order_id, shop_id และ group_id จาก Push ไว้ครบ
- หาก Push ฝั่งร้านไม่มี URL ครบ ระบบสร้างลิงก์ order_tab=seller ขึ้นใหม่ตอนกดแจ้งเตือน
- แถบ "มีออเดอร์ใหม่" จำร้านและออเดอร์ที่ทำให้เกิดการแจ้งเตือน
- กดแถบแจ้งเตือนแล้วเปิดออเดอร์ร้านนั้นโดยตรง ไม่ผ่านหน้าเลือกร้าน
- หากข้อมูลบางส่วนยังขาด จะค้นหาออเดอร์ล่าสุดที่ร้านต้องดำเนินการเป็นทางสำรอง
- ไม่กระทบเส้นทางของลูกค้าและ Rider

ติดตั้ง:
1. ต้องมี V0.5.22.108 แล้ว
2. วาง index.html, app.js, order.js และ sw.js ทับไฟล์เดิม
3. ไม่ต้องลง V0.5.22.109 หรือ .110 แยก หากใช้ไฟล์ .111 นี้
4. ไม่ต้องรัน SQL และไม่ต้อง Deploy Edge Function
5. ปิด Web App/PWA ให้สนิท แล้วเปิดใหม่หนึ่งครั้ง
6. ล้าง Notification เก่าที่ค้างอยู่ และสร้างออเดอร์ใหม่เพื่อทดสอบ
