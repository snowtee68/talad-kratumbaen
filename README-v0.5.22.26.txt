V0.5.22.26 - Rider Self Registration + Admin Approval

เพิ่มระบบ:
- ปุ่ม 🛵 สมัครเป็นวิน บน Web App
- ต้อง Login ก่อนสมัคร
- กรอกชื่อ / เบอร์โทร / พื้นที่รับงาน / ทะเบียนรถ
- สมัครแล้วสถานะ = รอตรวจสอบ
- สมัครแล้วไม่สามารถรับงานได้ทันที
- Admin มีรายการ “คำขอสมัครวินจากผู้ใช้” ในหน้าวิน/ไรเดอร์
- Admin กดอนุมัติหรือไม่อนุมัติได้
- เมื่ออนุมัติ ระบบเรียก market_admin_upsert_rider เดิมเพื่อเพิ่มเข้าทะเบียนวินเดิม
- ปุ่มผู้ใช้เปลี่ยนตามสถานะ:
  สมัครเป็นวิน -> รอตรวจสอบวิน -> งานวิน
- กรณีไม่อนุมัติ ผู้ใช้สามารถแก้ข้อมูลและสมัครใหม่ได้
- ทะเบียนรถใช้สำหรับ Admin ตรวจสอบ ไม่แสดงสาธารณะ

ไม่เปลี่ยน:
- rider_jobs เดิม
- Order / Mission / Coupon / Delivery logic
- UUID/Login เดิม

วิธีอัปเดต:
1) รัน upgrade-v0.5.22.26-rider-self-registration.sql ใน Supabase SQL Editor 1 ครั้ง
2) ทับไฟล์เว็บ
3) Commit + Push
4) Hard Refresh
5) ทดสอบด้วยบัญชีผู้ใช้ทั่วไปสมัคร 1 คน แล้ว Login Admin ไปอนุมัติ

หมายเหตุ:
ปุ่ม “งานวิน” ใน V0.5.22.26 เป็นจุดเข้าบัญชี/สถานะวินที่ได้รับอนุมัติ
ระบบการรับงาน Delivery ยังคงใช้ workflow rider เดิมของระบบ ไม่ได้สร้าง workflow รับงานชุดใหม่
