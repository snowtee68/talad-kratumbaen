# ตลาดกระทุ่มแบน Main v5.0

พัฒนาต่อจาก Main v4.4 โดยไม่เปลี่ยนระบบร้านเดิม

## ฟังก์ชันโปรโมชั่น
- เพิ่มโปรโมชั่น
- แก้ไขโปรโมชั่น
- เปิด/ปิดโปรโมชั่น
- ลบโปรโมชั่น
- คัดลอกโปรโมชั่นเดิมเป็นสำเนา (สำเนาจะถูกปิดไว้ก่อน)
- ปักหมุดโปรโมชั่นเด่น
- ตั้งวันเริ่มและวันสิ้นสุด
- สร้างโปรล่วงหน้าได้ไม่จำกัด
- ช่วงเวลาใช้งานซ้อนกันได้สูงสุด 3 โปรต่อร้าน
- ดูโปรที่กำลังใช้ กำลังจะเริ่ม หมดอายุ และปิดใช้งาน

## วิธีติดตั้ง
1. รัน `อัปเกรดโปรโมชั่น-v5.0.sql` ใน Supabase SQL Editor
2. นำไฟล์ทั้งหมดไปวางทับ Branch `main`
3. Commit และ Push
4. รอ GitHub Pages อัปเดต แล้วกด Ctrl+F5

## วิธีใช้งาน
เข้าสู่ระบบ > ร้านที่ฉันดูแล > จัดการโปรโมชั่น
